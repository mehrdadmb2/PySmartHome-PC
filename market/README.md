# Generated market snapshots

These JSON files are generated by `.github/workflows/update-market-snapshot.yml`.
Do not edit them manually; run the workflow to refresh the data.

- `currencies/usd.json`: USD/USDT reference rate in Toman.
- `metals/gold_18k_1g.json`: one gram of 18K gold in Toman.
- `esp32.json`: compact fixed-schema payload fetched by the PC market proxy.
- `status.json`: source timestamp, generated timestamp, freshness and output metadata.

The source is `mehrdadmb2/ArzPulse`'s `docs/data/latest.json`. The workflow validates
both source prices and converts IRR to Toman. It does not commit new files on an
invalid/missing source; the last known-good snapshot remains unchanged.

The PC application downloads only `market/esp32.json`, validates it, caches the
last good version, and exposes it at `/api/market` over the trusted local LAN. The
ESP32 boards must use the PC endpoint, not GitHub and not the full ArzPulse feed.
