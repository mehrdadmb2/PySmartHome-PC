# Generated market snapshots

These JSON files are generated by `.github/workflows/update-market-snapshot.yml`.

- `currencies/usd.json`: USD/USDT reference rate in Toman.
- `metals/gold_18k_1g.json`: one gram of 18K gold in Toman.
- `esp32.json`: compact fixed-schema payload fetched by the PC market proxy.
- `status.json`: source timestamp, generated timestamp, freshness and output metadata.

The primary refresh is event-driven: after the ArzPulse workflow named
`Update Market Data` successfully finishes publishing `docs/data/latest.json`,
its notifier sends `repository_dispatch` event `arzpulse_prices_updated` to
this repository. This workflow then imports the latest ArzPulse data, validates
it, converts IRR to Toman and commits only the generated files that changed.

Manual refresh remains available through `workflow_dispatch`. The ESP32 boards
must use the local PC endpoint `/api/market`, not GitHub and not the full
ArzPulse feed.

## Source files

- ArzPulse source: `https://raw.githubusercontent.com/mehrdadmb2/ArzPulse/main/docs/data/latest.json`
- ArzPulse Contents API: `https://api.github.com/repos/mehrdadmb2/ArzPulse/contents/docs/data/latest.json?ref=main`
- PySmartHome ESP32 snapshot: `https://raw.githubusercontent.com/mehrdadmb2/PySmartHome-PC/main/market/esp32.json`

Do not use the GitHub directory-view URL ending in `/tree/main/market` as a
JSON source; it serves HTML, not a data file.

## One-time cross-repository permission

ArzPulse must have repository secret `PYSMARTHOME_DISPATCH_TOKEN`, containing a
fine-grained token restricted to `mehrdadmb2/PySmartHome-PC` with
`Contents: Read and write`. GitHub requires this permission for the repository
dispatch endpoint. The token is used only by the ArzPulse notifier workflow and
must never be committed to either repository.
